Ciclo de vida de una solicitud

Las transiciones las controla el dominio; no existe edición libre del estado. Completed es terminal: nunca regresa a un estado anterior.

Pending

Registrada por el portal. Espera a que el procesador la tome.

→
Processing

Reclamada por el procesador; se invoca al proveedor externo con reintentos acotados.

→
Completed

El proveedor confirmó la operación. Estado final.

Failed

Se agotaron los reintentos por fallos transitorios.

Semántica de negocio

Estado de la solicitud · color + texto + forma

Pending Processing Completed Failed

Anillo punteado = aún no procesada · círculo = en curso o completada · rombo = requiere atención. Failed usa el tono critical, nunca el destructive, que queda reservado para errores del sistema.
